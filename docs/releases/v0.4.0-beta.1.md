# Dotmon v0.4.0-beta.1 — première bêta publique

Dotmon est un moniteur système et gestionnaire de tâches **natif Linux / Wayland**
(Rust + Slint, sans Electron), à l'esthétique inspirée de Nothing OS (sans logo ni police
propriétaires). Interface en français.

> ⚠️ **Bêta** : testé sur CachyOS + Hyprland uniquement. Des défauts sont possibles.

## Fonctionnalités principales
- Métriques réelles : CPU (par cœur), mémoire, disques, réseau, températures, GPU
  (NVIDIA via NVML, AMD via sysfs).
- **Veille NVIDIA préservée** : un GPU endormi n'est jamais réveillé par Dotmon.
- Liste des processus, regroupement par application, recherche, tris.
- Fermeture d'une application avec confirmation : **FERMER** (SIGTERM) puis, séparément et
  seulement sur demande, **FORCER** (SIGKILL). Aucune escalade automatique, confirmation
  liée à l'identité exacte du processus (PID + heure de démarrage, `pidfd`).
- Processus critiques protégés (PID 1, threads noyau, Dotmon lui-même, session
  Hyprland/Quickshell, PipeWire, portails, services système, processus d'autres utilisateurs).
- Mode `--mock` : machine simulée, pour la démonstration et les tests.
- Jamais exécuté en root, aucune élévation de privilèges.

## Installation

**Arch Linux / CachyOS (AUR, après publication des paquets)** :
```
paru -S dotmon        # compilation depuis les sources
paru -S dotmon-bin    # binaire précompilé (conflit déclaré avec dotmon)
```

**Depuis cette release** : télécharger `dotmon-0.4.0-beta.1-x86_64-linux.tar.gz`, vérifier la
somme (`sha256sum -c dotmon-0.4.0-beta.1-x86_64-linux.tar.gz.sha256`) puis, en connaissance de
cause, extraire l'arborescence `usr/` dans `/usr` ou `~/.local`.

**Depuis les sources** : voir le `README.md` (`packaging/arch`, `makepkg -si`).

Dépendances d'exécution : `glibc gcc-libs fontconfig wayland libxkbcommon hicolor-icon-theme ttf-font`.
Optionnelles : `nvidia-utils` (mesures NVIDIA), `libglvnd` (rendu OpenGL optionnel).

## Limitations connues
- Interface uniquement en français ; pas de support X11.
- Distributions visées : Arch Linux et CachyOS.
- Après une **première** installation, un Quickshell déjà lancé ne voit pas la nouvelle icône :
  `dbus-send --session --type=signal /KIconLoader org.kde.KIconLoader.iconChanged int32:0`
  ou redémarrage de Quickshell.
- Applications multi-processus : voir `docs/PHASE3.md`.
